## 🌲 How Spook Trees Work

Spook Trees are special Halloween trees that can spawn in **Lumber Tycoon 2 during October**.

They do not spawn in one specific biome. They can appear in many different places around the map as long as the game finds a valid outdoor spawn location.

### 🌍 Where They Can Spawn

Spook Trees can grow on valid surfaces such as:

- Ground
- Sand
- Slate
- Roads

The location normally needs to have **open sky above it**, which is why Spooks can sometimes appear in very strange places like:

- Player plots
- Cliffs
- Mountains
- Roads
- Islands
- Beaches
- Tropics
- Safari
- Taiga
- Areas near the volcano

Because of this, checking only normal forests is not enough.

---

## ⏱ Spook Spawn Timing

Spook spawning is based on timers inside the server.

The exact 2026 timing is not fully confirmed, but community testing from previous years suggests:

- New servers may have an initial random delay before the first Spook appears.
- Additional Spook spawn attempts happen several hours apart.
- Around **6 hours between spawn opportunities** has been commonly documented.
- Older servers therefore have had more chances for a Spook to spawn.

This does **not** mean every server will have a Spook after a certain number of hours.

A tree may have:

- Already been chopped
- Spawned somewhere difficult to see
- Been removed when somebody loaded a base
- Failed to spawn because no suitable position was found
